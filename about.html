About Online Tools

Privacy-first utilities that run entirely in your browser

What is this project?

Online Tools is a collection of free browser-based utilities for everyday tasks: working with PDFs, images, text and simple developer needs.

Everything is designed so that your files never leave your device. There is no account system and no server-side processing of user content.

Core principles

  • Privacy by default — processing happens in the browser
  • No registration — open the page and use the tool
  • No artificial limits — only what your device can handle
  • Honest descriptions — we tell you what a tool can and cannot do

Who is behind it

The project is maintained by an independent developer. If you find the tools useful, you can support further development via Boosty or crypto (see the main page).

For feedback or issues see the Contact page or open an issue on GitHub.
