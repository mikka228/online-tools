What is Image Resizer?

Change the width and height of an image while optionally keeping the original aspect ratio. Useful for thumbnails, social media sizes, or reducing resolution before upload.

How to use

  • Select or drop an image
  • Set new width and/or height
  • Keep aspect ratio on or off
  • Choose format and quality, then download

Privacy

Resizing runs fully in your browser with the Canvas API. The file is not uploaded to any server.

FAQ

What does Keep aspect ratio do?
When enabled, changing width automatically updates height (and vice versa) so the image is not stretched.

Is there a size limit?
Input files up to 20 MB. Max dimension is 10000 px.

Does resizing upload my image?
No. Everything uses the Canvas API in your browser.
