Feedback, bugs and suggestions

How to reach us

The preferred way to report bugs or request features is the GitHub repository:

github.com/mikka228/online-tools/issues

What is helpful to include

  • Which tool you used
  • Browser and device (if relevant)
  • What you expected and what happened
  • Steps to reproduce (if it’s a bug)

Support the project

If the tools save you time, you can support further development via Boosty or USDT (TRC20) — links are on the main page.
