UUID Generator

Generate UUID v4 identifiers

What is a UUID?

A UUID (Universally Unique Identifier) is a 128-bit value used to identify records, sessions and resources without a central authority. This tool generates version 4 (random) UUIDs.

How to use

  • Choose how many UUIDs you need (1–100)
  • Press Generate
  • Copy the result

Privacy

Generation uses the browser’s crypto API when available. Nothing is sent to a server.
