What is a QR Code Generator?

A QR code stores text, a website URL, or Wi-Fi login details in a square pattern that phones can scan. This generator builds the code in your browser and lets you download a PNG or SVG — useful for menus, event check-in, product packaging, or sharing a link without typing.

How to create a QR code

  • Enter a URL, plain text, or Wi-Fi details
  • Optionally change foreground/background colors and size
  • Download the PNG (raster) or SVG (vector, scalable)

Tips for reliable scans

  • Keep enough contrast between dark modules and light background
  • Do not stretch the image; scale it proportionally
  • Leave a quiet margin (white space) around the code when placing it on a design
  • Prefer SVG for print and high-resolution needs

Privacy

Your text never leaves the device. The code is drawn locally with a client-side library.

FAQ

Can I make a Wi-Fi QR code?
Yes — use the format WIFI:T:WPA;S:NetworkName;P:password;; in the text field.

Is the PNG high enough resolution for print?
Choose a larger size before download, or use SVG for perfect scaling.
