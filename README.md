# Online Tools

Free privacy-first browser utilities. No registration. No file uploads — everything runs on your device.

**Live site:** https://mikka228.github.io/online-tools/

## Principles

- **Privacy by default** — PDFs, images and text are processed in the browser
- **No accounts** — open a page and use the tool
- **Honest limits** — we describe what each tool can and cannot do
- **Open source** — all pages are in this repository

See [Privacy & Security](https://mikka228.github.io/online-tools/privacy.html) for details.
