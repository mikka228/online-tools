Privacy & Security

Last updated: November 25, 2026

🔒 Your files stay on your device. PDF, image and text processing runs in your browser. We do not upload the content of your documents to our servers.

How processing works

Online Tools is a set of static pages hosted on GitHub Pages. When you open a PDF or image, the browser loads the file into memory and runs JavaScript libraries (such as pdf-lib, PDF.js, Canvas API, JSZip) locally.

The file content is not sent to mikka228.github.io or any other backend for processing. There is no account system and no server-side storage of user files.

What we do not collect

  • Content of PDFs, images or text you process
  • User accounts or login data
  • Files after you close the tab (unless you saved something yourself via localStorage for history/settings)

Technical data

Like almost every website, the hosting provider (GitHub Pages) can see standard request metadata: IP address, user agent, which pages were requested and when. This is independent of the file processing that happens in the browser.

We currently do not use advertising trackers or heavy analytics scripts that would send page content elsewhere.

Libraries

All processing libraries are hosted locally within this repository under the vendor/ folder. No third-party CDN is required to load the tools. Your files are processed directly in your browser and are not uploaded to our servers.

  • pdf-lib — PDF creation and modification
  • PDF.js — rendering PDF pages to canvas
  • JSZip — building ZIP archives for batch downloads
  • jsPDF — creating PDFs from images
  • QR code library — drawing QR codes (bundled into the page)

The site itself is served by GitHub Pages infrastructure (standard page requests). That is separate from tool processing: document and image content is not uploaded for conversion or compression.

Local storage

A few features (for example “Recently used” on the homepage) may store small pieces of data in localStorage on your device. You can clear this at any time in your browser settings. This data does not leave your device.

How you can verify

  • Open DevTools → Network while using a tool
  • Select a file and run an operation
  • You should not see the file content being uploaded to our domain or third-party endpoints as part of processing

CDN requests for library scripts are expected; uploads of your document content are not.

Open source

The project source is public: github.com/mikka228/online-tools. You can inspect every page and script.

Contact

Questions about privacy: Contact or open an issue on GitHub.
